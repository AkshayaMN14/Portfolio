# 🚀 Akshaya M N Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **HTML, CSS, and JavaScript**. This portfolio showcases professional experience, technical skills, projects, and contact information with a clean UI, particle background effects, typing animation, and smooth scrolling.

---

## 📌 Features

### ✨ Modern UI Design

* Dark-themed professional portfolio
* Glassmorphism cards
* Responsive layout for Desktop, Tablet, and Mobile
* Smooth scrolling navigation

### 🎯 Interactive Elements

* Animated typing effect
* Particle.js animated background
* Scroll reveal animations
* Active navigation highlighting
* Back-to-top button
* Mobile hamburger menu

### 👨‍💻 Portfolio Sections

* Home
* About Me
* Experience
* Skills
* Projects
* Contact

---
